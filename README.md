## 🚀 Overview

ShowMyIP is a simple website written in HTML, CSS and JS with Bootstrap that displays a bunch of information about the visitors IP. Everything is powered by Free APIs.

## 🎯 Features

- Show's user's IP, ISP, Browser, OS, Device Type and Location
- Uses free APIs
- Easily deployable
- Responsive Design

## 🛠️ Installation

1. Go to the [Releases](https://github.com/chrstph-gg/showmyip/releases/latest) page and Download the latest Version
2. Upload to FTP or GitHub and host as a page
3. Visit your URL

## 💻 Used APIs (Free)

- [BigDataCloud](https://www.bigdatacloud.com/free-api)
- [IPLocation.net](https://api.iplocation.net/)
- [FlagsAPI](https://flagsapi.com/)
